# PgDL Study Desk

Original revision notes for English Legal System and Constitutional Law and Equity and Trusts, organised around 17 University of Law cohort units.

The website includes linked university readings, selected public primary sources, 17 recall cards, 13 practice exercises, two interactive issue-spotting aids, a concept map and browser-local revision progress. The published material is an independent revision aid, not an official university publication.

The default daily timeline has 32 dated actions across 28 October–10 November and the December/January results milestones. Each action pairs its task with readings, protected university links and exact document filenames where known. Every dated card offers an original downloadable text checklist. Official requirements, suggested study and conditional time-zone sittings are labelled separately. Completion ticks are browser reminders, not verified submissions.

## Local preview

Serve this directory with a static HTTP server and open `index.html`. No build, backend or API key is needed. External font and D3 resources improve appearance and the concept map; the notes and text equivalent remain available if they cannot load. Progress is saved in localStorage only.

## Publishing

GitHub Pages serves the `main` branch at the repository root. Publish only `index.html`, `style.css`, `app.js`, `content.js`, `review-mode.js` and this README. Local build notes and QA files are not part of the public repository.
